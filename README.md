**Удалённый доступ, где экран идёт по интернету, а мышь и клавиатура — через плату ESP32 (настоящее USB-HID).**

Управляемый ПК показывает свой экран через сервер-релей, а ввод получает не программно, а с воткнутой в него **платы ESP32-S2**, которая для этого ПК выглядит как обычная USB-клавиатура и мышь.

## 🎯 Что это

Вариант MouseKeyEmulator для случаев, когда ввод должен быть **аппаратным** и
неотличимым от настоящей мыши/клавиатуры:

- 🖥️ **Экран** управляемого ПК идёт вам по интернету (через релей).
- 🖱️⌨️ **Ввод** доставляется на управляемый ПК не программно, а через **плату
  ESP32-S2**, воткнутую в его USB — она вводит мышь/клавиатуру как настоящее
  USB-HID устройство.
- 🔗 Подключение по короткому **коду** (сквозь NAT, без проброса портов).
- 🔎 **IP платы определяется сам** — управляемый ПК находит свою ESP32 в сети,
  вводить адрес вручную не нужно. Несколько ПК и плат в одной сети — каждый
  привязан к своей плате, ввод не уходит на чужие.

## ⚙️ Как это устроено

```mermaid
flowchart LR
    A["🖥️ Ваш ПК"] -- "ввод" --> R(("☁️ Релей"))
    R -- "ввод" --> B["💻 Управляемый ПК<br/>+ приложение"]
    B -- "по USB (LAN)" --> E["🔌 ESP32-S2"]
    E -- "USB HID" --> B
    B -- "экран" --> R
    R -- "экран" --> A
```

Ввод: ваш ПК → релей → приложение на управляемом ПК → по локальной сети на
плату ESP32 → плата вводит как настоящая USB-клавиатура/мышь.
Экран: управляемый ПК → релей → ваш ПК.

## 🚀 Быстрый старт

1. **Прошейте ESP32-S2** — файлы и инструкция в [`firmware/`](firmware/). Задайте
   плате Wi-Fi и общий ключ.
2. Воткните плату в USB **управляемого** ПК.
3. Запустите **`MouseKeyEmulator.exe`** (из [Releases](../../releases/latest)) на
   обоих ПК, активируйте лицензию.
4. **На управляемом ПК:** включите «В сети» и продиктуйте код. Приложение
   **само найдёт плату ESP32** этого ПК в сети — её IP появится в карточке.
5. **На вашем ПК:** введите код → «Подключиться» → «Взять управление».

> Общий ключ должен совпадать: в приложении (обоих ПК) и в прошивке платы.
> Плата и управляемый ПК должны быть в одной локальной сети — тогда IP
> определяется автоматически.

### 🖧 Несколько ПК и плат в одной сети

Сценарий «3–5 управляемых ПК, у каждого своя ESP32» поддержан безопасно: каждая
плата сообщает свой **уникальный id**, и приложение привязывается ровно к
**одной** плате — ввод не уходит на чужие.

- Если в сети **одна** плата — она подхватывается автоматически.
- Если плат **несколько** — на управляемом ПК выберите свою из списка
  (запомнится). Сменить — кнопкой «Сменить».
- Привязка идёт по id, поэтому **смена IP** платы (DHCP/переподключение)
  отслеживается сама. При желании можно вписать IP вручную.

> Для уникального id нужна **прошивка v2.0.2+** — перепрошейте платы, если
> обновляетесь с более ранней версии.

## 🔒 Безопасность

- Сопряжение через релей защищено **кодом комнаты** и **общим ключом**: ключ
  проверяется по схеме **запрос-ответ HMAC-SHA256** — секрет не передаётся,
  перехват рукопожатия бесполезен, повтор (replay) невозможен.
- 🔑 Задайте **свой сильный общий ключ** в приложении (на обоих ПК) и в прошивке
  платы — по умолчанию он общеизвестный.
- ⚠️ Поток экрана/ввода через релей по умолчанию не шифрован на сервере — для
  конфиденциальности разверните релей за TLS.
